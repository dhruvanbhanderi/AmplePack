?? How to Use:

  1. Select Box Type: Single Wall or Double Wall
  2. Choose Sheet Size: Select from dropdown or choose "Custom" for custom dimensions
  3. Enter Box Dimensions: Length and Width in inches
  4. View Live Info: See boxes per sheet, efficiency, cost per blank automatically
  5. Preview Layout: Click "Preview Layout" to see SVG visualization
  6. Enable Sheet Costing: Check "Use Sheet-Based Material Cost" for exact sheet calculations
  7. Calculate Price: Click Calculate Price for final pricing
